# Design System v1.0 validation

Validated October 2, 2026 (America/New_York).

- Production Next.js build and static generation pass, including the new `/work/emilio-sierra-studio` route and both preserved project URLs.
- Strict TypeScript checking and ESLint pass.
- All seven browser tests pass.
- The browser suite uses an isolated production build (`.next-test`) on port 3100.
- Chrome automated accessibility scans cover the homepage, all three case studies and the inquiry preview using axe WCAG A/AA rules.
- Responsive checks cover the English homepage at 360, 390, 768, 1024, 1440 and 1920 CSS pixels and all Spanish page routes at 360, 390, 768, 1024 and 1440 pixels.
- Footer language switching translates page text, persists through navigation/reload, updates the document language and preserves entered form values.
- Three project disciplines, reduced-motion native scrolling and navigation changes between blue hour and daylight are checked.
- Desktop/mobile screenshots include fully loaded supplied images for visual review. They are generated in `test-results/`.
- Mobile navigation traps keyboard focus, closes on Escape, restores the trigger and follows section links.
- Inquiry preview submits no network request and explicitly reports that nothing was sent. Unknown project routes return 404.

Automated scans alone do not establish full WCAG conformance. Manual screen-reader review, real-device/cross-browser checks, production performance measurement, email delivery and publication details remain on the launch checklist.

The original brief matches its preserved v0.8 copy byte for byte. The pre-v1.0 source/media snapshot is in `docs/versions/source-before-v1.0.tar.gz`.
